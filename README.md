# ALMA AI — Android Beta

**ALMA AI** is an AI-powered project exploring human behavior and long-term relationship compatibility.

This repository provides the Android beta version of ALMA AI for testing and feedback.

## Download

Download the latest APK from the repository or the Releases section.

**APK file:** [ALMA-AI.apk](./ALMA-AI.apk)

## Installation

1. Download the APK file to your Android device.
2. Open the downloaded file.
3. If prompted, allow your browser or file manager to install apps from this source.
4. Complete the installation and launch ALMA AI.
